# IntervAI

### Your Interview. Your Future.

IntervAI is an AI-powered mock interview and assessment platform that analyzes resumes, conducts personalized interviews, evaluates candidate answers and generates performance reports.

## Technology Stack

- Frontend: React.js, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Service: Python, FastAPI
- AI: Gemini API, Groq API
- RAG: LangChain, LangGraph, ChromaDB

## Project Structure

- frontend/ – React application
- backend/ – Express REST API
- ai-service/ – Python AI microservice
- docs/ – Project documentation
- tests/ – Automated tests
